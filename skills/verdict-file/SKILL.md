# Verdict File — канон машиночитаемого вердикта

## 1. Зачем

Вердикт свободным текстом нельзя ветвить и нельзя посчитать. Канон задаёт единый формат
файла вердикта и границы записи.

## 2. Формат

**Расположение:** рядом с проверяемым артефактом — `ИМЯ_АРТЕФАКТА.verdict.md`.
Для review-loop историческое имя `REVIEW.md` допустимо — формат тот же.

**Первая строка — единственный источник истины для автоматики:**

```
verdict: PASS | FAIL | ESCALATE
```

Далее обязательные секции:

```markdown
# Verdict: ЧТО_ПРОВЕРЯЛОСЬ
**Дата:** YYYY-MM-DD · **Проверяющий:** РОЛЬ_АГЕНТА · **Проход:** review-loop | verifier-pass | orthogonal

## Проверял
- ПУТЬ_СТРОКА_ИЛИ_КОМАНДА_ИЛИ_URL — что реально открыто/выполнено

## Не сошлось
- severity: critical|major|minor · area: ФАЙЛ_ИЛИ_СЕКЦИЯ · claim: ЧТО_НЕ_ТАК · evidence: ПОЧЕМУ_ИСТОЧНИК
(при verdict: PASS секция пустая или «—»)

## Не проверял
- ЧТО_ОСТАЛОСЬ_ЗА_РАМКАМИ_И_ПОЧЕМУ
```

> **Обозначения плейсхолдеров.** В каноне `VERDICT_FILE.md` плейсхолдеры записаны в угловых
> скобках. Здесь они заменены на верхний регистр и «ёлочки» намеренно: гейт
> `verify_gate.py` считает незаполненным любой текст в угловых скобках и поднимает FAIL
> на документах-исходниках (см. «Известный дефект гейта» в README плагина). Смысл полей
> идентичен канону.

## 3. Маппинг вердиктов

| VERIFIER_PASS | Файл вердикта |
|---|---|
| `OK` | `PASS` |
| `LIST[замечания]` | `FAIL` |
| `ESCALATE[причина]` | `ESCALATE` |

## 4. Зоны записи

- **Проверяющий** пишет **только** файл вердикта. Он не правит проверяемый артефакт.
- **Оркестратор** не пишет ни одной строки в файл вердикта — он вносит исправления
  по замечаниям и закрывает их отдельным отчётом.

## 5. Механика (MiniMax Code)

- Проверка формата — скриптом: `python scripts/verdict_gate.py ФАЙЛ.verdict.md` (exit 0/1).
  PASS ставит только скрипт.
- Структурная приёмка самого артефакта — `python scripts/verify_gate.py АРТЕФАКТ`.
- Агрегация вердиктов по проекту — в волне 2 (как `quality-log.py verdicts` у MyAI):
  сбор `*.verdict.md` и агрегация по датам.

## 6. Связанные каноны

- `КАТАЛОГ_КАНОНОВ\VERDICT_FILE.md` v1.0 — формат и зоны записи
