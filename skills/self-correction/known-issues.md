# Известные проблемы (справочник self-correction)

Справочные данные к скиллу `self-correction`. Читать при соответствующих симптомах — при диагнозе (шаг 2) и выборе новой стратегии (шаг 3).

## Windows / Кодировка
- **cp1252 в консоли**: PowerShell 5.1 и cmd.exe используют ANSI по умолчанию. `print("кириллица")` упадёт с `UnicodeEncodeError`. Решения: curl, запись в файл с `encoding="utf-8"`, или Python с флагом `-X utf8`.
- **PowerShell файловые операции**: `Get-Content`/`Set-Content` по умолчанию — ANSI. Всегда указывай `-Encoding UTF8`.
- **Heredoc с не-ASCII**: Bash heredocs (`<< 'EOF'`) могут испортить не-ASCII на Windows. Используй инструмент `write`.

## Qdrant
- **Большие scroll-запросы**: Scroll >1000 точек без пагинации может зависнуть или вернуть неполные данные. Всегда используй `limit` + `offset` (или `next_page_offset`).
- **Delete endpoint**: `POST /collections/{name}/points/delete` с `{"points": [id1, id2, ...]}`. Пакуй по 100–500 штук.
- **Кэширование metadata коллекции**: Информация о коллекции (количество точек, конфиг векторов) редко меняется в рамках задачи. Запрашивай один раз, переиспользуй.

## Инструмент write
- **Баг сериализации dict**: Инструмент `write` может сериализовать Python dict вместо записи текста, если аргумент — не строка. Всегда передавай plain string. После записи — ЧИТАЙ файл для проверки.
- **Тихие сбои**: Успешный вызов write не гарантирует корректное содержимое. Всегда проверяй.
