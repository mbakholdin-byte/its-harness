# Пакет `its-harness` — дистрибутив харнеса НПО ИТС для MiniMax Code

**Версия:** 0.6.7 · **Формат:** MiniMax Plugin V1 (локальный плагин)
**Назначение:** «коробка» из видения конструктора харнеса — скиллы + MCP + хуки в одном пакете. Bootstrap-файл ставит пакет и персонализирует (опросник → манифест → доменные роли → приёмка).

## Установка (локальный плагин)

1. Скопировать каталог `its-harness/` в локальную plugin-директорию MiniMax Code (панель **Plugins → Local**, `Ctrl+R` для обновления списка; точный путь локальной директории показывает `mcode plugin marketplace list` в CLI).
2. В панели `/plugins` включить пакет (Space).
3. Для hmem (ОПЦИЯ, только если нужна MCP-память и установлен Node.js): установить `npm i -g hmem-mcp`, задать переменные окружения (см. таблицу выше) и вручную вернуть в `plugin.json` блок `"mcpServers": ["its-harness.mcp.json"]`. **Внимание:** с этим блоком плагин НЕ загружается на машинах без Node.js — это был дефект v0.6.5 (клиент отвечал «Local skill not found» на все скиллы пакета), исправлено в v0.6.6 вынесением MCP в опцию.
4. Проверка: `/skills` показывает скиллы пакета; новая сессия показывает уведомление SessionStart-хука. **Плагин подхватывается только при старте клиента** — после копирования перезапустить MiniMax Code.
